
# CO2 Emission Prediction Using Multiple Linear Regression

## Project Overview
This project predicts the carbon dioxide (CO2) emissions of a vehicle using Multiple Linear Regression. It uses vehicle specifications and fuel consumption information to estimate emissions in grams per kilometer.

## Objectives
- Predict vehicle CO2 emissions using machine learning.
- Study the relationship between vehicle specifications and emissions.
- Display model performance through an interactive dashboard.
- Provide a simple web interface for users to test predictions.

## Input Features
- Engine Size (L)
- Number of Cylinders
- Combined Fuel Consumption (L/100 km)

## Output
Predicted CO2 emissions in grams per kilometer (g/km).

## Technologies Used
- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Machine Learning Algorithm
Multiple Linear Regression

## Website Features
- Home dashboard
- CO2 emissions prediction
- Model analytics
- Dataset preview
- Model evaluation metrics

## Dataset
The project uses the vehicle fuel consumption ratings dataset published by the Government of Canada.

Dataset source:
https://open.canada.ca/data/dataset/98f1a129-f628-4ce4-b24d-6f16bf24dd64

## How to Run Locally

1. Clone or download this repository.
2. Open a terminal in the project folder.
3. Install the required libraries:

   pip install -r requirements.txt

4. Start the Streamlit application:

   streamlit run app.py

5. Open the local URL displayed in the terminal.
